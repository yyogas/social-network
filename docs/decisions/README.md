# Décisions et ADR

Créer un fichier par décision approuvée : `DEC-0001-titre-court.md` ou `ADR-0001-titre-court.md`. Conserver les propositions dans une section distincte tant qu'elles ne sont pas approuvées.

Champs minimaux : ID, titre, date, auteur ou autorité, statut, objectif, problème, options évaluées, décision retenue, alternatives rejetées, dépendances, risques, impacts produit/business/technique/sécurité/privacy, migration, rollback et date de réévaluation si utile.

Les décisions historiques `DIR-001` à `DIR-008` sont dans `../00-hq/registry.md`. Aucun `DEC-0001` ni `DEC-0002` n'est encore approuvé.
