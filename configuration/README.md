# Configuration

Exemples sans secrets, sous la responsabilité de 14 DevOps et 20 Code Source. Le fichier `examples/.env.example` indique l'état documentaire actuel. Lorsque les contrats seront définis, chaque variable devra être documentée avec type, contraintes, valeur par défaut, portée et mécanisme de fourniture. Ne pas créer de configuration runtime supposée à partir d'un simple nom de technologie.
