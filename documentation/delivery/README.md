# Livraison et exploitation

Propriétaires : **14 DevOps / SRE**, **18 QA / Release**, **20 Code Source**, **21 Intégration / Code Review**. **17 Documentation** tient les références à jour.

M0 demande l'état réel du repository, les critères de revue et d'intégration, une matrice de tests du parcours pilote, les exigences d'observabilité et un plan de mise en production proportionné au risque. Un test n'est `PASS` qu'après exécution ; une release n'est `READY` qu'après ses gates.

**Statut :** aucun test ou déploiement confirmé dans ce dépôt initial.
