Les repères `D17-A` à `D17-D`, `ECART-17-*` et `AC-DOC17-*` ci-dessous sont locaux à cet index, sans réservation d'IDs dans les registres globaux. Les anciens IDs F01/F02 des brouillons hors Git ne sont pas automatiquement des alias FEAT-001/002 : 01/17 doivent vérifier le sens avant toute table de correspondance.

Quatre axes évitent les faux raccourcis :

| Axe | Valeurs / preuve |
| --- | --- |
| Nature de l'affirmation | CONFIRMÉ, PROPOSÉ, À VÉRIFIER ; citer la source ; NON REÇU si la pièce manque dans le périmètre consulté |
| Revue du document | PROPOSÉ → EN REVUE → APPROUVÉ avec autorité, date, portée et SHA ; une nouvelle révision exige examen de son delta |
| Réalisation | Non implémenté ou non vérifié selon les faits ; IMPLEMENTED exige fichier/commit/build, VERIFIED une exécution précise |
| Transmission / test | À TRANSMETTRE → ENVOYÉ → REÇU ; séparément PLANNED → READY → RUNNING → PASS/FAIL/BLOCKED pour chaque exécution |

Un document fusionné peut rester PROPOSÉ. Un PASS ancien reste attaché à son SHA. En cas de remplacement, conserver le motif et le lien successeur ; ne pas effacer la décision ou le résultat qui explique l'histoire.
